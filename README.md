# Python Slot Machine

A terminal-based slot machine game built with Python.

## How to run

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open Terminal in the project folder and run: `python3 main.py`

## How to play

- The game starts with a balance and asks you to deposit money.
- Choose how many lines (1 to 3) you want to bet on.
- Choose the bet amount for each line.
- The slot machine spins and shows the symbols.
- If a full line has the same symbol, you win. Rarer symbols pay more.
- Press Enter to play again, or type `q` to quit and keep your balance.
